# Website Profil & Pemesanan Online Surah Kopi

Website resmi kedai **Surah Kopi** (@surahkopi - Tangerang Selatan).

## 🚀 Pembaruan Fitur Terkini
1. **Modal QRIS Mudah Ditutup**:
   - Dapat ditutup melalui tombol silang (✕) di bagian atas, tombol *"✕ Tutup Jendela QRIS"* di bagian bawah, klik pada area luar modal (backdrop), ataupun menekan tombol keyboard **Escape (Esc)**.
   - Dapat dibuka kapan saja dari navbar atau tombol *"Scan QRIS"* tanpa harus mengisi keranjang terlebih dahulu.
2. **Kalkulator Ongkos Kirim GoSend & GrabExpress**:
   - **Titik Asal (Origin)**: Surah Kopi Tangerang Selatan (Ciputat).
   - **Wilayah Tujuan (Destination)**: Pilihan kecamatan/wilayah populer di Tangerang Selatan (Ciputat, Pamulang, Bintaro Sektor 1-9, BSD City, Serpong, Pondok Aren, Alam Sutera, Gading Serpong, Lebak Bulus) atau input jarak kilometer manual.
   - **Rumus Tarif Resmi**:
     - *GoSend Instant*: Min 0-4 km = Rp 15.000, km berikutnya = +Rp 2.800/km.
     - *GrabExpress Instant*: Min 0-4 km = Rp 14.000, km berikutnya = +Rp 2.600/km.
     - *Ambil Sendiri*: Rp 0 (Gratis).
3. **Pilihan Kemasan & Logika Es**:
   - **Kemasan Botol Ready to Go**: Opsi es otomatis **disembunyikan** karena minuman botol disajikan dingin segar tersimpan rapat tanpa es batu (rasa tidak akan hambar/mencair di perjalanan).
   - **Cup Standar**: Opsi es tetap tampil (*Normal Ice, Less Ice, Es Dipisah di Plastik*).
4. **Desain Monochrome & Menu Berwarna**:
   - Layout berkonsep minimalis hitam putih modern.
   - Foto minuman tetap tampil berwarna asli, segar, tajam, dan menggugah selera dengan animasi hover halus.
